GDD asset gallery

Public but unlisted: search engines are asked not to index this page. Anyone with the URL can view it.

This gallery is generated from the tracked Shrinkonauts repository at deploy time. It contains 98 runtime manifest entries, 304 review previews, 45 concept plates, 17 historical screenshots, 7 character-source images, 34 action shots and 26 documents.

Status key

  • runtime — shipped runtime art; some entries are POC integrated with final approval pending.
  • action — a live-app gameplay screenshot from the walkthrough.
  • placeholder — declared, but no final art yet.
  • manifest-only — processed and declared, but not wired into the current scene.
  • preview / source — review previews or source plates, not runtime assets.
  • historical — old milestone screenshots.

What is not here

  • No generated capture binaries in git; action shots are rebuilt by npm run gdd:capture and merged by npm run gdd:site.
  • No static contact sheets or gdd-picks/ folders; the gallery replaces them.
  • No theme files; three pilot SFX are installed and the remaining 15 cues are placeholders.
  • No ignored local-only plates (full-size keyed files, raw hub batch).

Known visual gaps

  • The 04 Muscle Effector sky, material atlases, gate and exit are wired; its far/mid/near layers remain declared placeholders.
  • The 03 concept gate gate-nerve-01 is authored but not loaded; the concept-gate overlay is captured on Silicon.

Licences

AI-generated art is logged as own work with the tool and the current POC licence label. The two fonts are Silkscreen and Pixelify Sans, both SIL OFL 1.1. In-repo placeholder atlases are CC0-1.0. The Ludo/Nano Banana plan, prompt, model and seed are still TBD; see Licence notes and Asset list.
