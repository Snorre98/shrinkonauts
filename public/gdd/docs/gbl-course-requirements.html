6. GBL acceptance checklist

  • Report Introduction has Name, Purpose, Platform, Short description, Technology.
  • Theory ≤1000 words; application-only; 3–4 course readings cited; four core lenses + Kiili supporting.
  • GDD has Learning, Gameplay, UI/Controls, Monetization; illustrations; theme; not a technical report.
  • GDD Learning section uses learning-design-brief.md/curriculum-alignment.md (not a parallel narrative).
  • Video ≤2:00, 16:9, unlisted, not for kids, embedding allowed; shows problem + concept; music/SFX/captions.
  • Asset list separates own vs. sourced; licences complete.
  • Reflection ≤250 words; development process + theory.
  • References list all papers/sources; every citation appears.
  • Playtest evidence: 3 external players/pairs; pre/post; think-aloud; debrief rubric.
  • GBL submitted by 9 November; confirmation recorded.
  • Final delivery index includes the GBL report/GDD/video/asset list by 24 November.
