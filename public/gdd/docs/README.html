Shrinkonauts — GDD asset pack

Copied from the working docs. Some cross-links may still point to the original repository or Obsidian vault.

Local, gitignored copies of the art, concepts, screenshots and review sheets for the Game Design Document. Built from the current working tree on 2026-11-02.

This folder is for the GDD/video/playtest work. It is not served by the game and nothing here is referenced by a runtime manifest. The originals remain in public/, art-source/ and screenshots/.

Online gallery: the same library is published at https://snorre98.github.io/shrinkonauts/gdd/ with search and filters. The web version is generated from the tracked sources in CI; the local-only gdd-picks/ and contact-sheets/ folders are not published.

Size: about 26 MB (28 MB on disk; gdd-picks/ is hard-linked to the library where possible). Files: 565, including 62 runtime manifest entries (58 runtime, 2 placeholder, 2 manifest-only), 38 concept plates, 214 review previews, 25 character-source files, 17 screenshots and 10 contact sheets.

The public gallery adds 34 action shots captured from the live app. They are generated by npm run gdd:capture and are not copied into this local pack. See CAPTURES.md and the online walkthrough.

What is actually final

  • Bathroom hub: the scene plate, washer body/door/drum, civilian, poster, cartridges, plush, basket, cycle icons and the reused P1 tiny astronaut are wired final art. Towel and detergent bottles are manifest-only; the logo uses the approved Silkscreen CSS fallback and the toy astronaut is cut.
  • Anatomy: P1/P2 idle + walk/jump/fall/land sheets, Neuron Keeper static + 36-frame idle, scan.synapse, scan.muscle, pad.dendrite, pad.terminal, gate.ferry, prop.tracer, pulse.terminal, both receptors, the pretty nerve-forest sky, the final 04 sky, the four coloured material atlases, and the final 04 gate/exit sprites are runtime art.
  • 04 source batch: the seven Nano Banana plates in art-source/nanobanan/new/muscle-endplate-2026-11-03/ are processed, wired and accepted. The manifest, licences, prompt log and tests are complete.
  • Silicon: all listed sprites and the board sky are runtime art. The circuit atlas is still a placeholder SVG.
  • Placeholders: colored 48×48 squares with four-letter labels in the captures are procedural placeholder sprites, not tiles. The current visible ones are sprite.scan.neuron (yellow NEUR), sprite.scan.pathway (cyan PATH), sprite.scan.interrupt (cyan INTE) and sprite.exit.silicon (yellow SILI). See ../assets/prompt-library-v01.md.
  • Audio: cue and theme playback are implemented. Three pilot SFX (scan, jump, land) are installed in the Anatomy and Silicon packs; the other 15 cues and all four themes remain placeholders. The hub cues are still placeholders.
  • UI: the game HUD, dialogue, map, concept log, debrief and pause menu are CSS/DOM, not raster assets. They are visible in the action-shot walkthrough; see CAPTURES.md.

Using these files in Canva / the PDF

  1. Start with gdd-picks/ for the page you are building. The full library is there if you need a different crop or a larger version.
  2. Prefer PNG with alpha for sprites and WebP for backgrounds. If Canva will not accept a WebP, convert it to PNG first (the source WebP is lossless).
  3. Pixel art is provided at 1x, 2x, 4x and 8x in previews/. Use 4x/8x for page illustrations; use 1x/2x only when you want to show actual size.
  4. Do not upscale a 1x sprite in Canva. Use the 4x/8x preview instead.
  5. Label placeholder-era screenshots as “prototype — placeholder art”. Do not imply they show final art.
  6. Do not use concepts/anatomy/sprite-agent-neuron.jpg as the Neuron Keeper; the runtime character is final/anatomy/sprites/agent-neuron.png (and the idle sheet agent-neuron-idle.png). The concept plate is an alternate.
  7. Do not use the failed parallax references (bg-nerve_forest-far.jpg, -mid.jpg, -near.jpg); use the -updated plates or the background previews.

How the pack was made

  • final/ is copied from the assets.final.json manifests. assets.final.json, licenses.json, theme.json, pack.json/hub.json, mapping.json, materials.json and level JSONs are copied into each pack's metadata/.
  • previews/ is copied from art-source/previews/. No new game captures were made.
  • concepts/ contains every Nanobanan JPEG resized to a 1280 px long edge (JPEG q86). The originals remain in art-source/nanobanan/.
  • characters/ contains the Ludo source sheets (resized to 1800 px long edge), their JSON atlases, the working masters, palettes and clips.json.
  • contact-sheets/ is generated with ImageMagick from the copied files.
  • The public action shots are generated by the Playwright capture pass and merged by npm run gdd:site; see CAPTURES.md.
  • ASSET-INDEX.md, manifest.json and gallery.html are generated from the manifests, source reports and the copied files.
  • source/notes/gbl/ contains copies of the GBL requirements, learning-design brief, curriculum alignment, theory brief and GBL README when the Obsidian vault is present.
  • gdd-picks/ is a small, page-oriented selection; it is hard-linked where the filesystem allows it.

The detailed commands and the source-to-runtime chain are in PIPELINE.md.

Regenerating

The local gdd-assets/ pack is generated by a local-only script that is ignored with the pack; it is not present in a clean checkout. The public gallery is built by the tracked npm run gdd:site command below.

From the repository root, on a machine that has the local pack script:

node gdd-assets/tools/build.mjs

Requires Node 24 and ImageMagick 7 (magick). The script resets the generated folders (final/, previews/, concepts/, characters/, screenshots/, contact-sheets/, source/, gdd-picks/, manifest.json, ASSET-INDEX.md, gallery.html) and rebuilds them. It does not delete this README or the other hand-written docs.

It reads the current working tree, so uncommitted art changes are included. The manifest records the commit hash and whether the tree was dirty.

To build the public GitHub Pages gallery instead:

npm run gdd:capture    # writes ignored gdd-captures/
npm run gdd:site       # writes public/gdd/ and merges the action shots
npm run gdd:smoke      # smoke the generated gallery and walkthrough
npm run build:site     # writes public/gdd/ and runs the production build

The public gallery is generated from tracked sources in CI; public/gdd/ is gitignored and should not be committed.

Not regenerable from a clean checkout: the raw hub batch art-source/nanobanan/new-main-menu/ is ignored and absent on this machine. Only the processed hub exports, previews and reports are available. The full Ludo source sheets are in art-source/characters/, so those are reproducible.

  • No third-party images or audio are included.
  • Gaps: prompt/model/seed logs, the Ludo/Nano Banana plan, and some licenses.json entries are still missing. See LICENCE-NOTES.md and ASSET-LIST-GBL.md.
