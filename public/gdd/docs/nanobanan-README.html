Background removal

npm run art:key decodes the JPEG through ffmpeg, keys the flat magenta by RGB distance, suppresses magenta spill on the edge pixels, and writes a hard-alpha PNG. Full-size keyed copies go to keyed/ (ignored). Review previews go to art-source/previews/nanobanan/.

npm run art:key -- \
  --in art-source/nanobanan/new/sprite-scan-ferry-v2.jpeg \
  --out art-source/nanobanan/keyed/gate-ferry.png \
  --key "#ff00ff" --tolerance 0.18 --despill --trim \
  --preview art-source/previews/nanobanan/gate-ferry-key.png \
  --preview-width 512 --background "#101a20"

The default --tolerance 0.18 and --softness 0.08 are tuned for these JPEGs. If a plate has a soft or noisy edge, raise --tolerance before lowering --alpha-threshold; the latter trades fringe for holes in the subject.

The keyed copies are pre-trimmed, so the fit report’s “source content touches the image border” warning is expected and does not mean the original plate was clipped. Check the keyed preview when in doubt.

Entity fit

npm run art:fit takes the keyed PNG, crops to alpha bounds, fits the configured cell without stretching, hard-thresholds alpha, quantises to the approved non-orange ramps, and writes the runtime PNG, previews and a JSON report.

Hero pass (2026-11-02, ADR-0075). The hero configs (fit.new.config.json and fit.silicon.config.json) are schema 2 and declare per-class cells: hero-npc 96×96, hero-interactable 64×64, hero-prop 48×48, ui-1x 36×36. The older fit.config.json and fit.badge.config.json remain schema 1 for legacy 18×18 / badge review. The palette cell is advisory; the fit cell wins. The reports record the class, display, treatment, source scale and gates. The 2026-11-02 pass re-fitted the Keeper sheet, CPU, gates, consoles, sockets, receptors, pads and props as fit-preview; hand cleaning is still required before any hero asset is marked final. The Keeper sheet is now 3456×96 (36 frames at 96×96) and the CPU static is 96×96.

The original scan batch is in fit.config.json. The 2026-11-01 batch is in fit.new.config.json; it includes the accepted gate, tracer, pulse terminal, and both receptors plus the placeholder-only reflex audit. The badge has its own 16×16 palette and config (palette.badge.json, fit.badge.config.json) and is not wired.

Sky

The current sky is the pretty 2752×1536 source. It is the only wired 03 background and the recorded exception to the pixel-art palette/quantisation rules: it keeps the muscle-pink drapes and is not palette-quantised. The runtime plate is a 2672×1536 side crop (40 px each side) that matches the 1280:736 room aspect, Lanczos-downscaled to 1280×736 and exported as lossless WebP:

mkdir -p art-source/nanobanan/working/tmp
ffmpeg -y -v error \
  -i art-source/nanobanan/new/bg.nerve_forest.sky.jpeg \
  -vf "crop=2672:1536:40:0,scale=1280:736:flags=lanczos" \
  -pix_fmt rgb24 \
  art-source/nanobanan/working/tmp/nerve-forest-sky-pretty-1280x736.png

cwebp -quiet -lossless -q 100 -m 6 \
  art-source/nanobanan/working/tmp/nerve-forest-sky-pretty-1280x736.png \
  -o public/packs/anatomy-reflex/shared/backgrounds/nerve-forest-sky.webp

The result is a 1280×736 VP8L WebP of 978,732 bytes (~956 KiB). No art:normalize pass and no palette.nerve-forest-sky.json are used. The previews are previews/nanobanan/backgrounds/nerve-forest-sky-pretty-1280x736.png and -1280x720.png; the 1280×720 preview drops the 8 px top/bottom that the 720-high viewport crops. The earlier 640×368 quantised sky and its nerve-forest-sky-updated-2x.png preview are retained for comparison only.

Parallax layers

The far/mid/near plates are flat #FF00FF cut-outs retained for a future layered pass. Each is cropped to an exact 2048×1024 window (far: x=432,y=416; mid/near: x=432,y=208), keyed at full resolution, nearest-downscaled to 1024×512, quantised with palette.nerve-forest-layer.json (no tissue role), 2×2-snapped and 2 px edge-welded. The weld makes opposite edges pixel-identical; it does not hand- repaint the composition across the seam. These layers are not wired in the current 03 runtime.

# Far; use x=432,y=208 for mid/near
ffmpeg -y -v error \
  -i art-source/nanobanan/new/bg-nerve_forest-far-updated.jpeg \
  -vf "crop=2048:1024:432:416" \
  art-source/nanobanan/working/tmp/background-far-2048x1024.png

npm run art:key -- \
  --in art-source/nanobanan/working/tmp/background-far-2048x1024.png \
  --out art-source/nanobanan/keyed/background-far-keyed.png \
  --key "#ff00ff" --tolerance 0.18 --softness 0.08 \
  --preview art-source/previews/nanobanan/backgrounds/background-far-keyed.png \
  --preview-width 1024 --background "#101a20" \
  --report art-source/nanobanan/reports/background-far.key.json

ffmpeg -y -v error \
  -i art-source/nanobanan/keyed/background-far-keyed.png \
  -vf "scale=1024:512:flags=neighbor" -pix_fmt rgba \
  art-source/nanobanan/working/tmp/background-far-1024x512.png

npm run art:normalize -- \
  --in art-source/nanobanan/working/tmp/background-far-1024x512.png \
  --palette art-source/nanobanan/palette.nerve-forest-layer.json \
  --out art-source/nanobanan/working/tmp/background-far-quantized.png \
  --preview art-source/previews/nanobanan/backgrounds/background-far-quantized.png \
  --scale 1 --background "#101a20" \
  --report art-source/nanobanan/reports/background-far.normalize.json

npm run art:tile-clean -- \
  --in art-source/nanobanan/working/tmp/background-far-quantized.png \
  --out art-source/nanobanan/working/tmp/background-far-clean.png \
  --band 2 --min-component 4 --snap2x2 \
  --weld-x union --weld-y union \
  --report art-source/nanobanan/reports/background-far.clean.json

cwebp -quiet -lossless -q 100 -m 6 \
  art-source/nanobanan/working/tmp/background-far-clean.png \
  -o public/packs/anatomy-reflex/shared/backgrounds/nerve-forest-far.webp
