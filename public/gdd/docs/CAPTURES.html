Copied from the working docs. Some cross-links may still point to the original repository or Obsidian vault.

The public gallery includes a Gameplay walkthrough built from the live app, not from hand-picked screenshots. The captures are stills at 1280×720 taken by Playwright using the system Chrome installation.

  • Published page: gdd/walkthrough.html
  • Capture command: npm run gdd:capture
  • Gallery merge: npm run gdd:site
  • Gallery smoke: npm run gdd:smoke

The generated files are not committed:

gdd-captures/                 ignored
  captures.json               capture metadata sidecar
  <slug>.png                  1280×720 viewport screenshots

npm run gdd:site copies the PNGs to public/gdd/captures/, writes a public captures.json, and merges the sidecar into public/gdd/manifest.json. npm run build then copies public/gdd/ into dist/gdd/.

Metadata

Every entry carries:

  • id — stable slug and walkthrough anchor
  • title — human label
  • flow — hub / launch / 03 / 04 / silicon / modes
  • pack — hub / anatomy / silicon
  • level, room — content IDs where applicable
  • beat — state name, e.g. node-run-threshold
  • mode — solo / co-op / n/a
  • objectiveIds, conceptIds — curriculum links
  • relatedAssets — runtime manifest IDs
  • whatToNotice — 1–2 sentence caption
  • art — final or placeholder
  • order — walkthrough order
  • alt — accessible image description
  • docs — rendered doc slugs
  • compareWith, compareLabel — optional comparison pair

The capture sidecar adds file, width, height and capturedAt. scripts/gdd-site.ts validates slugs, dimensions, doc slugs and related asset IDs before merging.

Capture mechanics

  • Uses the existing Playwright channel: "chrome" and 1280×720 viewport.
  • Boots with the existing ?skipMenu=1&pack=... shortcut and drives the app with the same teleport / waitForRoom / overlay helpers as the smoke tests.
  • Asserts app state before each screenshot: room id, HUD text, overlay role, feedback surface ID/state or runtime snapshot.
  • Polls the HubScene for the drum angle (spin) and tiny astronaut (shrink) instead of sleeping for a guessed cinematic duration.
  • Pauses the Phaser loop for the screenshot and uses animations: "disabled" so transient effects do not move between the assertion and the capture.
  • HUD-free key-art shots hide only the presentation layers; the game state is unchanged.
  • Fails on console errors or failed HTTP responses in each flow.

CI

The verify job runs the capture before gdd:site:

npm run gdd:capture
npm run gdd:site
npm run gdd:smoke
npm run build

A capture failure uploads gdd-captures/, test-results/ and playwright-report/ as a failure artifact. The deploy workflow is unchanged: it publishes the dist artifact, which already contains the merged gallery.
