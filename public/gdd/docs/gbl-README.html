A 2D exploration platformer learning adventure. A tiny repair crew dives into a gamepack — a simulated system on a cartridge — and repairs it from the inside. The first pack is anatomy; the first slice is the knee-jerk reflex arc. The body is the level; the cells are the agents; understanding the system is the key. Every system is a puzzle.
